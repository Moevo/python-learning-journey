# 🛒 Restaurant System - Nakhleh Shop
This project is a Python-based restaurant management system built using Jupyter Notebook.  
It simulates operations for a sandwich and meat shop, including ordering, pricing, and basic system logic.
---
## 🧠 System Logic
- User selects items from menu  
- System calculates total price  
- Handles multiple orders  
- Simulates real shop workflow
---
## 📂 Project File
- `nakhleh shop to sandwich and meat shop.ipynb`
